# tugasWeb

## Deskripsi Project

`tugasWeb` adalah project website sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript. Website ini memiliki halaman utama dengan sapaan otomatis berdasarkan waktu, menampilkan jam saat ini, serta kutipan inspiratif.

Website ini juga memiliki halaman kedua yaitu halaman **Tentang Saya** yang dapat diakses melalui tombol navigasi.

## Fitur Website

1. **Sapaan Otomatis**
   - Menampilkan sapaan berdasarkan waktu.
   - Selamat pagi, siang, sore, dan malam.

2. **Jam Digital**
   - Menampilkan waktu saat ini secara otomatis.

3. **Kutipan Inspiratif**
   - Menampilkan kutipan inspiratif secara acak.
   - Menggunakan DummyJSON API.
   - Menerjemahkan kutipan ke bahasa Indonesia menggunakan MyMemory Translation API.
   - Menyediakan kutipan lokal jika API tidak tersedia.
   - Memiliki tombol untuk menampilkan kutipan lainnya.

4. **Halaman Tentang Saya**
   - Menampilkan halaman Tentang Saya.
   - Menyediakan tombol kembali ke halaman utama.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- DummyJSON API
- MyMemory Translation API

## Cara Menjalankan Website

1. Clone repository:

   ```bash
   git clone https://github.com/nasril0/tugasWeb.git
   ```

2. Masuk ke folder project:

   ```bash
   cd tugasWeb
   ```

3. Buka folder menggunakan Visual Studio Code.

4. Jalankan file `index.html` menggunakan browser atau ekstensi Live Server.
